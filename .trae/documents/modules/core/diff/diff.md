# Diff 模块设计与架构

## 模块定位

- 位置：`src/core/diff/`
- 目标：对文本差异进行分组、策略化处理，为工具链与编辑应用提供可操作的变更单元。

## 目录结构

- `insert-groups.ts`：插入分组逻辑
- `strategies/`：差异策略（合并、粒度、优先级）

## 关键职责

- 将原始 diff 转换为可操作的分组与步骤
- 根据策略调整编辑顺序与冲突解决

## 核心接口

- `groupInserts(diffs, options)`：输出分组结构
- 策略：`DiffStrategy`（粒度、冲突处理）

## 数据流与交互

- 输入：原始 diff（行/字符级）
- 处理：分组→策略应用→输出操作列表
- 输出：可执行变更清单（apply、rollback）

## 配置与扩展点

- 分组与合并策略可插拔
- 与编辑工具联动（applyDiffTool 等）

## 错误处理与日志

- 冲突检测与回退
- 大型 diff 的性能监控

## 测试覆盖

- 分组正确性与策略效果
- 冲突场景下的行为验证
