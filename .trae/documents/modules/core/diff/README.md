# Diff 差异比较模块

## 1. 模块概述

Diff 模块负责文件和内容的差异比较功能，提供高效的差异检测、可视化展示和合并操作，支持多种文件格式和比较策略。

## 2. 文档结构

- `diff.md` - 差异比较模块功能概览和使用指南
- `diff-architecture.md` - 差异比较模块架构设计文档

## 3. 主要功能

- **文件比较**: 比较两个或多个文件的差异
- **内容分析**: 深度分析内容变化
- **可视化展示**: 提供直观的差异展示界面
- **智能合并**: 自动或半自动合并冲突
- **历史追踪**: 跟踪文件的变更历史

## 4. 核心组件

- **DiffEngine**: 差异比较引擎
- **DiffRenderer**: 差异渲染器
- **MergeResolver**: 合并解决器
- **ChangeTracker**: 变更跟踪器
