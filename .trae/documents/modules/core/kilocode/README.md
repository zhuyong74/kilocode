# Kilocode 核心模块

## 1. 模块概述

Kilocode 模块是整个系统的核心入口，负责系统初始化、模块协调、生命周期管理和全局状态维护，是连接各个子模块的中枢。

## 2. 文档结构

- `kilocode.md` - 核心模块功能概览和使用指南
- `kilocode-architecture.md` - 核心模块架构设计文档

## 3. 主要功能

- **系统初始化**: 启动和初始化整个 Kilocode 系统
- **模块管理**: 协调和管理各个子模块
- **生命周期控制**: 管理系统的启动、运行和关闭
- **全局状态**: 维护系统级的全局状态
- **事件调度**: 处理系统级事件和消息

## 4. 核心组件

- **KilocodeCore**: 核心控制器
- **ModuleManager**: 模块管理器
- **LifecycleManager**: 生命周期管理器
- **EventDispatcher**: 事件调度器
