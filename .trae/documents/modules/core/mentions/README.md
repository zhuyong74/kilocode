# Mentions 提及模块

## 1. 模块概述

Mentions 模块负责处理对话中的提及功能，包括用户提及、文件提及、符号提及等，提供智能的提及识别、解析和处理能力。

## 2. 文档结构

- `mentions.md` - 提及模块功能概览和使用指南
- `mentions-architecture.md` - 提及模块架构设计文档

## 3. 主要功能

- **提及识别**: 自动识别对话中的各种提及
- **提及解析**: 解析提及的类型和目标
- **提及处理**: 处理不同类型的提及请求
- **智能建议**: 提供智能的提及建议
- **上下文关联**: 建立提及与上下文的关联

## 4. 核心组件

- **MentionDetector**: 提及检测器
- **MentionParser**: 提及解析器
- **MentionHandler**: 提及处理器
- **SuggestionEngine**: 建议引擎
