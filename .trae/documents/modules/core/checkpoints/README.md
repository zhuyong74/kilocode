# Checkpoints 检查点模块

## 1. 模块概述

Checkpoints 模块负责管理任务执行过程中的检查点机制，提供任务状态保存、恢复和回滚功能，确保任务执行的可靠性和连续性。

## 2. 文档结构

- `checkpoints.md` - 检查点模块功能概览和使用指南
- `checkpoints-architecture.md` - 检查点模块架构设计文档

## 3. 主要功能

- **状态保存**: 在关键节点保存任务执行状态
- **状态恢复**: 从检查点恢复任务执行
- **回滚机制**: 支持任务执行失败时的状态回滚
- **增量保存**: 优化存储空间的增量状态保存
- **并发控制**: 多任务环境下的检查点管理

## 4. 核心组件

- **CheckpointManager**: 检查点管理器
- **StateSerializer**: 状态序列化器
