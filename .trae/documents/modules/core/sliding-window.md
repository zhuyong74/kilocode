# Sliding Window 模块设计与架构

## 模块定位
- 位置：`src/core/sliding-window/`
- 目标：实现滑动窗口策略，用于分批处理上下文/数据，控制提示长度或处理粒度。

## 目录结构
- `index.ts`：窗口策略实现
- `__tests__/`：策略行为测试

## 关键职责
- 根据窗口大小与步长切分输入
- 为任务/工具提供批处理与分页能力

## 核心接口
- `createSlidingWindow(size, step)`、`iterate(items)`

## 数据流与交互
- 输入：序列数据或文本
- 处理：切分→迭代→回调处理
- 输出：批次结果聚合

## 配置与扩展点
- 自适应窗口大小（基于令牌/字符）
- 边界对齐策略（完整语句/代码块）

## 错误处理与日志
- 输入为空/过长的防御
- 批次失败的重试与回滚

## 测试覆盖
- 不同窗口/步长组合的正确性
- 边界切分与聚合一致性
