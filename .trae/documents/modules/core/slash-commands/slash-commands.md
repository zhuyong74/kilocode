# Slash Commands 模块设计与架构

## 模块定位

- 位置：`src/core/slash-commands/`
- 目标：管理斜杠命令的注册与解析（如 `/kilo`），用于快速触发核心功能。

## 目录结构

- `kilo.ts`：核心斜杠命令定义与路由

## 关键职责

- 注册与解析命令参数
- 路由到对应核心功能（模式切换、任务创建、工具调用）

## 核心接口

- `registerSlashCommands(registry)`、`handleSlashCommand(input, ctx)`

## 数据流与交互

- 输入：斜杠命令文本
- 处理：解析→验证→路由→执行
- 输出：执行结果（UI/日志/上下文）

## 配置与扩展点

- 命令集的扩展与别名支持
- 参数模板与自动补全

## 错误处理与日志

- 非法命令/参数的提示
- 执行耗时与审计

## 测试覆盖

- 多命令解析的正确性
- 路由与执行的一致性
