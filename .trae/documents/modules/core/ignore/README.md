# Ignore 忽略规则模块

## 1. 模块概述

Ignore 模块负责管理文件和目录的忽略规则，提供灵活的过滤机制，支持多种忽略模式和规则配置，确保系统只处理相关文件。

## 2. 文档结构

- `ignore.md` - 忽略规则模块功能概览和使用指南
- `ignore-architecture.md` - 忽略规则模块架构设计文档

## 3. 主要功能

- **规则解析**: 解析各种格式的忽略规则
- **模式匹配**: 高效的文件路径模式匹配
- **规则管理**: 动态添加、删除和修改忽略规则
- **继承机制**: 支持规则的层级继承
- **性能优化**: 优化大规模文件过滤性能

## 4. 核心组件

- **IgnoreManager**: 忽略规则管理器
- **PatternMatcher**: 模式匹配器
- **RuleParser**: 规则解析器
- **FilterEngine**: 过滤引擎
