# Context 上下文模块

## 1. 模块概述

Context 模块负责管理和维护任务执行过程中的上下文信息，提供上下文的创建、更新、查询和传递功能，确保任务执行的连续性和一致性。

## 2. 文档结构

- `context.md` - 上下文模块功能概览和使用指南
- `context-architecture.md` - 上下文模块架构设计文档

## 3. 主要功能

- **上下文创建**: 为新任务创建初始上下文
- **上下文更新**: 在任务执行过程中更新上下文信息
- **上下文查询**: 提供高效的上下文信息查询接口
- **上下文传递**: 在不同组件间安全传递上下文
- **上下文持久化**: 支持上下文的持久化存储

## 4. 核心组件

- **ContextManager**: 上下文管理器
- **ContextStore**: 上下文存储器
- **ContextSerializer**: 上下文序列化器
- **ContextValidator**: 上下文验证器
