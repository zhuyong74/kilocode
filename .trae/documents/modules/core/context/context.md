# Context 模块设计与架构

## 模块定位

- 位置：`src/core/context/`
- 目标：管理核心上下文（指令与管理），用于构建系统/用户/任务的上下文与提示。

## 目录结构

- `context-management/`：上下文聚合与管理
- `instructions/`：指令模版与生成

## 关键职责

- 聚合多来源上下文（文件、任务、模式、用户输入）
- 维护系统/用户/工具指令的生成与更新

## 核心接口

- `buildContext(task, settings)`：返回完整上下文包
- `getSystemInstructions(mode)`、`composeUserInstructions(inputs)`

## 数据流与交互

- 输入：任务状态、模式配置、文件上下文
- 处理：聚合→去重→排序→生成指令
- 输出：上下文包与提示词片段

## 配置与扩展点

- 指令生成的策略插件（语言、风格、详略）
- 上下文来源权重与裁剪

## 错误处理与日志

- 缺失来源/冲突信息的处理
- 生成耗时与质量监测

## 测试覆盖

- 多来源聚合的正确性与裁剪质量
- 指令生成在不同模式下的一致性
