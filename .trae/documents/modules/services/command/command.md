# Command 服务设计与架构

## 模块定位
- 位置：`src/services/command/`
- 目标：统一注册与执行系统命令，封装权限校验与结果处理。

## 目录结构
- `commands.ts`：命令定义与注册
- `built-in-commands.ts`：内置命令集合
- `__tests__/`：命令行为与 frontmatter 解析测试

## 关键职责
- 定义标准化命令接口与生命周期
- 处理参数解析、权限校验、执行与结果回传
- 支持前置/后置钩子扩展

## 核心概念
- `Command`：标识、描述、参数、执行函数
- `CommandRegistry`：注册与查找命令
- `ExecutionContext`：传递环境、权限、日志句柄

## 数据流与交互
- 注册期：收集命令 → 建立索引
- 执行期：解析参数 → 权限校验 → 执行 → 格式化结果

## 对外 API
- `register(command)`、`execute(name, args, ctx)`
- `list()`、`describe(name)`

## 配置与扩展点
- 权限策略适配器（角色/范围）
- 结果格式化器（文本/结构化/富文本）

## 错误处理与日志
- 细粒度异常分类（校验、执行、外部依赖）
- 执行耗时与审计日志

## 测试覆盖
- 参数解析与权限分支
- 内置命令快照与回归
