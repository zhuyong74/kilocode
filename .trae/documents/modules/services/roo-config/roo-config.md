# Roo Config 服务设计与架构

## 模块定位
- 位置：`src/services/roo-config/`
- 目标：统一加载与解析 Roo 配置，提供给核心与其他服务使用。

## 目录结构
- `index.ts`：配置加载、校验与导出接口
- `__tests__/index.spec.ts`：配置案例测试

## 关键职责
- 从文件/环境中加载配置
- 验证配置合法性并提供类型安全的访问

## 核心接口
- `loadConfig(paths)`、`validate(config)`、`get(key)`

## 数据流与交互
- 输入：路径或默认位置
- 处理：读取→解析→校验→缓存
- 输出：配置对象或错误信息

## 配置与扩展点
- 多来源合并（文件、环境变量、远端）
- 校验规则可扩展（schema）

## 错误处理与日志
- 缺失/不合法配置的分类与提示
- 加载/校验耗时记录

## 测试覆盖
- 多案例与合并策略
- 校验失败分支
